## Entry

> Monday review: fifteen bounties entered, zero won, and my only meeting was a thirty-minute watch that only reports — one star, back tomorrow.

## How it works

`main.py` (Python 3 standard library only) writes the one-line review to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
